ПИКСЕЛЬНЫЙ ПИСЮН: СТРОЙКА ВЕКА — версия для компьютера (v1.1.0)

ЗАПУСК
  Windows : двойной клик по run.bat   (сам поставит pygame)
  Linux/macOS: ./run.sh
  Вручную : pip install pygame  ->  python main.py   (python main.py --fullscreen — на весь экран)

EXE (по желанию)
  Windows : build_exe.bat  -> dist\PixelPisun.exe
  Linux/macOS: ./build_exe.sh

УПРАВЛЕНИЕ
  ← → / A D    ходьба
  Пробел / Z / K  прыжок (в воздухе — двойной)
  Shift (держать) бег
  ↑ / W        лестница вверх (режим «Генерация»), в остальных режимах — прыжок
  ↓ / S        вниз по лестнице
  G / F / X    граната («Битва за Писюн»)
  E / Enter    «ПОСТРОИТЬ» и листание реплик (пробел тоже листает реплики)
  Esc / P      пауза / меню
  F11          полный экран
  Мышь работает как один палец (меню, кнопки).

КО-ОП С ТЕЛЕФОНАМИ
  Компьютер и телефоны играют вместе — у них один и тот же сетевой протокол.
  1. Все устройства в одной Wi-Fi сети (у компьютера можно и по кабелю в тот же роутер).
  2. Кнопка КО-ОП -> «СОЗДАТЬ ИГРУ» на одном устройстве, остальные видят её в списке серверов.
  3. Windows при первом запуске спросит про брандмауэр — разреши доступ в частных сетях,
     иначе телефоны не увидят сервер (хостишь с компьютера) или не подключатся.
  4. Если список пуст (на роутере включена изоляция клиентов / гостевая сеть) —
     кнопка «ПО IP» и адрес хоста (виден в лобби). Порты: UDP 47310, TCP 47311–47322.
  Профиль (ник, скин) хранится в файле pisun_profile.json в домашней папке пользователя.
